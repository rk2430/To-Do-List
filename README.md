# Weekly To-Do List App

A simple and beautiful Weekly To-Do List application built using **React JS**.  
This app allows users to:

- Add daily tasks
- Delete tasks
- Organize tasks for each day of the week
- Responsive design for mobile and desktop

---

## Features

- Add tasks for:
  - Monday
  - Tuesday
  - Wednesday
  - Thursday
  - Friday
  - Weekend

- Delete tasks anytime
- Responsive card layout
- Clean UI with pastel theme
- Built using React Hooks (`useState`)

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/weekly-todo-list.git
```

### 2. Navigate to Project Folder

```bash
cd weekly-todo-list
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Project

```bash
npm start
```

The app will run on:

```bash
http://localhost:3000
```

---

## How It Works

### Add Task
- Type a task in the input box
- Click the **Add** button
- Task will appear in the selected day card

### Delete Task
- Click the **Delete** button beside the task
- Task will be removed instantly
